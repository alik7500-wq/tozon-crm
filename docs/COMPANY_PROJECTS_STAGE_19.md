## Behavior

The scoped offer dialog has a separate Download PDF action. It lazy-loads jsPDF and bundled DejaVu Sans font subsets; the fonts support Russian and Tajik and include their license. No third-party PDF service or external font host is used. Font loading finishes before a fresh scoped offer-preview request. Only the newly authorized response is used to create and save the PDF. An access or stale-price error removes the preview and does not save a file. The regular browser print action remains available.

PDF content includes the actual apartment status, own project/complex, dimensions, total, deposit, remaining amount, term, approximate monthly payment, manual reference rate, authenticated preparer and preliminary-calculation note. Full-payment output omits a misleading monthly payment. Text wraps and long names can continue on another page. The normal RU/TJ example fits one A4 page. Native print preview is no longer required for direct PDF generation; its prior verification limitation remains separate.
